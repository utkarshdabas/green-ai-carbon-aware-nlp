# Green AI: Carbon-Aware Efficient NLP Model Optimization

This project investigates energy-efficient NLP model optimization using techniques such as pruning, quantization, knowledge distillation, and LoRA.

## Technologies

- Python
- PyTorch
- Hugging Face Transformers
- CodeCarbon
- Streamlit

## Models

- DistilBERT
- BERT Base
- T5 Small
- Distilled Student
- LoRA BERT

## Evaluation Metrics

- Training Time
- CO₂ Emissions
- Validation Loss
- Exact Match (EM)
- F1 Score
- Carbon Efficiency

## SDG Alignment

SDG 13 – Climate Action
